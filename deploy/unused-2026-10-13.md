# Неиспользуемые объекты MedOnline (13.10.2026)

Как искал: обход от пунктов меню всех **используемых** ролей (без «НЮ» 22–24, «Расходы по услугам» 18 и роли 2)
и стартовых страниц ролей из таблицы `Roles`: адрес → контроллер → страница → адреса на странице → и так далее.

## Что не трогать (выглядит неиспользуемым, но работает)

Бланки КДО (`med/kdo/forms`, `print`, `header`, `footer`), бланки амбулатории (`med/amb/forms`, `print`) — открываются по номеру формы;
справочники аптеки (`/drugs/dict/<код>.s`); QR-страница результатов (`/amb/qrcode.s`); шаблоны врача (`/templates/lv/*` из `fms-templates.js`);
мобильное API и боты.

## Как удалять

1. Сначала п.1 (служебные адреса) — это ещё и безопасность.
2. Модули из п.2 по одному: удалить контроллер и JSP, собрать, проверить меню ролей.
3. Таблицы — только после резервной копии: сначала `RENAME TABLE x TO zz_x` на месяц, затем `DROP`.
